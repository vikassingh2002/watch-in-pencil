# Watch in Pencil

Adapted from Deepwatch by Aditya Chaubey:
https://github.com/Aditya-Chaubey/readitya/tree/main/public/deepwatch

Upstream source downloaded 5 November 2026. The original application,
recommendation engine and catalog are retained. Changes add Desk navigation,
Vikas branding, a notebook palette, suggested starting topics, an isolated
storage key, and renamed exports. No existing user history was copied.

Vikas confirmed on 5 November 2026 that Aditya has no objection to reuse.

Video state is local to each browser and is not connected to the Desk's
Supabase synchronization. Export/import in Settings provides backups.
The catalog is curated, not all of YouTube; optional API settings are inherited.
